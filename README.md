# 控制理论知识图谱 · Control Theory Atlas

一个**完全离线**的交互式控制理论学习网站。图谱采用**自上而下的问题导向结构**，从左到右共 10 列：

> 🎯 研究方向(4) → ❓ 控制问题(17) → 🛠 解决方案(17) → ⑦ 鲁棒与先进 → ⑥ 非线性 → ⑤ 最优与估计 → ④ 状态空间设计 → ③ 经典设计 → ② 系统分析 → ① 建模基础

所有箭头统一表示**拆解/依赖**：车辆动力学、自动驾驶、机器人、无人机四大方向的每个控制问题，经由解决方案一路拆到最右端的最小知识点（第一性原理）。40 个知识节点每个都有直觉解释、严格定义、**完整证明**（KaTeX）、Python 参考实现，其中 21 个带**浏览器内实时交互仿真**（LQR 倒立摆、PID 调参、EKF/粒子滤波定位、MPC、Super-Twisting、Smith 预估器……）。

## 新增：控制之美 · 交互课程（course.html）

基于《控制之美》卷 1（控制理论从传递函数到状态空间）和卷 2（最优化控制、MPC 与卡尔曼滤波器）做成的**逐章交互式课程**，面向没有控制基础的读者。共 36 课、70 多个可拖可调的实时仿真，每课按“故事引子 → 核心直觉 → 公式（逐个符号解释，推导可折叠）→ 亲手调参 → 小测验 → 要点总结”组织。

- 入口：服务器运行后打开 http://localhost:8318/course.html ，或在图谱顶栏点“📘 控制之美 · 交互课程”。
- 卷 1：动态系统与开/闭环、卷积、微分方程建模、拉普拉斯变换与传递函数、状态空间、特征值与解耦、相平面（含“爱情故事”）、一阶/二阶系统（含“密室破案”、无人机项目经理）、稳定性、PI 控制（体重管理）、根轨迹与补偿器、PID、频率响应与伯德图（可以真的听的调音台）、能控性、极点配置、LQR、轨迹追踪、观测器与分离原理、附录线性化与傅里叶。
- 卷 2：矩阵指数与离散化、矩阵求导与线性回归（复现书中 13061 次梯度下降）、最优控制代价函数、动态规划（无人机 6×4 网格逐级填表）、HJB、离散/连续 LQR、三种轨迹追踪方法、MPC（滚动优化、QP、Φ/Γ/H/F 矩阵、约束、无人机案例）、数据融合与协方差、卡尔曼滤波、KF+MPC、EKF。
- 书中例题参数与关键数值均已核对（如 LQR 增益 [24.1421, 7.0203]、离散 LQR 收敛到 0.61803、动态规划最短时间 82/15 s、例 5.5.1 含约束首步 [5, −3]）；书中未给数值的仿真参数由本页面补充并在页面中注明。
- 代码：`course/engine.js`（矩阵运算、ZOH 离散化、连续/离散 Riccati、Ackermann、Hildreth QP、MPC 矩阵与约束构造、自适应画布绘图、控件）、`course/app.js`（路由、目录、进度）、`course/lessons/*.js`（每章内容与仿真）。进度只保存在本机浏览器（localStorage）。支持深色模式与手机屏幕。

## 使用方法

方式一（推荐，任选其一）：

```bash
node serve.js 8318
```

然后浏览器打开 http://localhost:8318 。

方式二：直接双击 `index.html`（部分浏览器对 file:// 有脚本限制，若空白请用方式一）。

## 功能

- **知识图谱**：节点按依赖关系分层布局，箭头表示"先学 A 再学 B"；悬停高亮前置/后继，图例可按分类过滤；拖动平移、滚轮缩放。
- **详情页**：左侧是全部理论的分类导航（当前项高亮，可直接切换），右侧内容按页签组织——💡 直觉 / 📐 定义 / 🧾 证明 / 🎛️ 实验 / 💻 代码，避免单页过长。
- **学习路线**：顶栏"📜 学习路线"给出 30 站的推荐顺序（保证每站前置已覆盖）；每个详情页底部有"上一站/下一站"。
- **搜索**：顶栏搜索框支持中英文与关键词（回车跳转，↑↓ 选择）。
- **交互实验**：每个实验都有滑块可实时调参（如 LQR 的 Q/R 权重、PID 三参数、滑模边界层），并给出数值 readout；倒立摆可以点击画布"踢一脚"。

## 技术说明

- 纯静态：HTML + CSS + 原生 JS，无框架、无构建、无外网依赖（KaTeX 已本地化于 `assets/katex/`）。
- 数值内核（`js/sim-engine.js`）：RK4 积分、高斯消元、矩阵指数、CARE/DARE Riccati 求解（DRE 积分法 / 迭代）、Durand–Kerner 多项式求根、频率响应与稳定裕度计算、投影梯度 QP（MPC 用）。
- 内容组织（`data/content/*.js`）：每个理论一个对象 `{sections, code, sim}`，用 `String.raw` 存 LaTeX；新增理论只需在 `data/nodes.js` 加节点/边，再写一个内容对象。
